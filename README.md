# 🌐 LingoSphere — Real-Time AI Voice Calling & Language Tutor

**Package ID:** `com.aistudio.lingosphere.kxpqzm`

LingoSphere is an Android language learning application built with Kotlin, Jetpack Compose, Material 3, Firebase Authentication, Cloud Firestore, Google Play Billing 8.0.0, and Gemini AI real-time bidirectional voice tutoring.
